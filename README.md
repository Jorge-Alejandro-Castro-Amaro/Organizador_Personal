• Nombre del proyecto: Organizador Personal
• Objetivo: Aplicar de forma integrada el flujo de preparación, versionamiento y colaboración de un proyecto.
• Tecnologías utilizadas: Python, Git
• Pasos de instalación: Clonar el repositorio:

git clone https://github.com/usuario/Organizador_Personal.git
cd Organizador_Personal
Crear y activar entorno virtual:

py -m venv .venv
.\.venv\Scripts\activate
Instalar dependencias:

pip install -r requirements.txt
Ejecutar la aplicación:

python src/main.py
